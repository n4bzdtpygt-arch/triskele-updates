Import a venue's rig: lights from the paperwork, positions from the plot

  • Patch → Import Rig…: choose the venue's channel hookup or instrument schedule (the PDF from Lightwright), a CSV or an exchange file, then Place Them from the Plot… and choose their plot PDF. Every light comes from the paperwork, exactly; each position it names ("#1 ELEC", "LX1", "DSR"…) is placed where the plot draws it, each bar as long as its pipe.
  • Starting from a plot instead: Add the Venue's Paperwork….
  • The positions list marks what to check: a question mark for a similar name or a boom (plots write a boom's name beside it), a dash for a position the plot doesn't show (left in a row to place by hand).
  • The plot is kept with the show and drawn under the stage plan, lined up, so you can see each position sits on its pipe. Plot beside the zoom buttons shows or hides it.
